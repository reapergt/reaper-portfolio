# Reaper Portfolio

A dark, animated portfolio built with Next.js, Tailwind CSS and Framer Motion.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Deploy to Vercel

1. Create a GitHub repository.
2. Upload this project.
3. Go to Vercel and import the GitHub repository.
4. Vercel detects Next.js automatically.
5. Deploy.

## Customize

Edit `components/Portfolio.tsx`:
- `skills` controls the skills cards.
- `projects` controls the project cards.
- Change the bio and text directly in the component.
- Replace the YouTube and Discord links if needed.
